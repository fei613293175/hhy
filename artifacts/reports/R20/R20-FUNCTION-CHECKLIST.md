# R20 功能清单

- Android 红包活动管理：全部、进行中、未开始、已结束筛选与真实状态展示。
- Android 创建/编辑红包：关联内容、数量、单个金额、定向规则、投放时间、保存草稿和提交预审核。
- Android 预审核结果：服务端状态刷新、业务摘要、版本审计及合法动作控制。
- Android 红包报价确认：服务端本金/服务费/应付金额、支付渠道、不可退款提示和订单创建。
- Admin 红包活动列表：统计、筛选、分页、状态、金额和详情入口。
- Admin 红包预审核：待审队列、证据与版本上下文、通过/拒绝动作及幂等/权限约束。
- Backend / 数据库：活动、版本、报价、订单、库存与审计事实源，含迁移、状态约束和测试。
- 可观测性：R20 指标、告警规则与静态门禁已进入 CI。
