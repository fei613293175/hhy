# R20 真机测试说明

1. 安装 `hhy-r20-8c9c1da-test.apk`。包名为 `cc.orbexa.hhy.debug`，使用 R13 起固定的 Hhy Staging Test V2 签名。
2. 登录已实名且具备广告主资格的测试账号，进入“我的”并打开“红包活动管理”。
3. 检查全部、进行中、未开始、已结束筛选，确认状态、总额、已发放、数量、单价和时间来自服务端真实数据。
4. 新建红包，填写已发布且归属当前广告主的内容 ID、数量、单个金额、定向规则和有效时间；验证保存草稿不会直接进入支付。
5. 提交预审核，确认重复点击不会重复创建活动，结果页展示服务端状态、版本和活动摘要。
6. 对已通过预审核的活动获取报价，核对本金、服务费、应付总额、报价编号和活动版本；金额不得由客户端自行变化。
7. 在允许的测试支付环境创建订单，确认不可退款提示清晰；重复点击或网络重试不得生成重复订单。
8. 分别验证无广告主资格、内容不归属、金额/数量越界、时间非法、版本冲突和离线恢复路径。
9. 记录手机型号、Android 版本、账号、测试时间、每一步结果、requestId 和异常截图。
