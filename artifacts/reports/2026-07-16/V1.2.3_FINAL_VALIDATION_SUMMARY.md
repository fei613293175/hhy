## 已关闭的最后问题

1. **可移植项目指纹误差**：重建环境导入 Python 库时生成 `__pycache__`，曾被错误计入项目指纹；现已禁用字节码并在重算前清理运行时缓存。
2. **提交主题未自动绑定 Story**：`prepare-commit-msg` 现会自动补充 `[STORY-ID]` 或 `[TASK-ID]`，并与 Trailer、Session 和 Checkpoint 交叉校验。
3. **CR 索引共享可变对象**：改为不可变快照写入，防止完整 CR 被写成空对象。
4. **关闭检查点覆盖 READY 状态**：关闭顺序已重排为实现提交 → Close → 关闭检查点 → 关闭元数据提交 → 最终状态投影。
5. **Active Pointer 未随检查点刷新**：每次检查点同步 Session、Actor、Task、Story、租约、Checkpoint 和项目指纹。
6. **历史 Commit 使用当前工作区误验**：pre-push/CI 现从每个历史 Commit 的 Git Tree 重建文件集合和指纹。
7. **一键接手脚本权限**：Git Hooks、Python CLI 和 Shell 接手脚本均以可执行权限打包；`./scripts/resume-project.sh` 已直接执行通过。
8. **任意中途交接缺少可移植证据**：Handoff ZIP 现在包含 Git Bundle、WIP Patch、安全未跟踪快照、Context Pack、Manifest 和 SHA-256。
