# 合伙云 Pro R05 精确视觉规格补充任务说明

## 目标

为 R05 单一实名认证补齐可直接施工、可量化验收的精确效果图和视觉参数。业务功能、字段、动作、状态和文案以包内页面规格与合同为准；效果图只负责页面建模、区域顺序、信息层级、布局、对齐、组件形态和视觉样式，不得增加虚拟业务。

## 必须交付的七组视觉规格

1. `SCR-ID-001` Android 实名认证首页：未认证、认证中、已认证三种状态。
2. `SCR-ID-002` Android 实名信息输入：默认、字段错误、授权说明弹层、网络失败重试。
3. `SCR-ID-003` Android 活体检测容器：准备、相机授权、加载、处理中、失败重试。
4. `SCR-ID-004` Android 实名结果：核验中、人工审核、成功、拒绝、失败、过期。
5. `H5-012` 活体回跳：加载、处理中、成功、人工审核、未通过、失效、离线。
6. `ADM-ID-001` 管理端实名列表：加载、正常列表、空列表、无权限、失败。
7. `ADM-ID-002` 管理端实名详情与复核：加载、详情、敏感资料授权、人工复核、乐观锁冲突、无权限、404。

## 每组必须包含

- 以页面 ID 命名的高保真 PNG，移动端按 1080×2400 基准，管理端按 1440×900 基准；响应式差异另附图。
- 对应的 Markdown 或 JSON 参数表：画布、安全区、区域顺序、左右/上下间距、组件宽高、字号、行高、字重、圆角、边框、颜色、阴影、遮罩、动画和各状态差异。
- 所有数值必须绑定包内 `hhy_design_tokens_v1.2.2.json` 已登记 Token；确需新增 Token 时必须单独列出原因和建议值，不能静默使用框架默认值。
- Android 页保持 `B12/P04` 的白底、标准顶栏、蓝色主状态卡、白色信息卡、列表行和主按钮视觉体系；不得采用当前实现中的居中 Hero 或自创准备卡片。
- 每张图标注其覆盖的页面 ID 与状态，禁止用 `P01-P08`、`TOKENS_ONLY` 或“参考相邻页面”代替精确绑定。

## 业务过滤硬边界

- 不复制参考图中的示例姓名、身份证号、日期、已完成假状态和无关功能。
- 不展示请求编号、TraceId、state、会话 ID、供应商代码、失败码、AppKey、SecretRef、接口名或异常栈。
- 用户页只展示“发生了什么、下一步怎么做”的商业文案。
- 管理端敏感信息默认脱敏；查看原文、人工复核和冻结操作必须保留权限、用途、二次确认和审计结构。
- 第三方实名认证 AppKey 尚未配置只影响活体供应商调用，不得把授权说明、本地表单或基础页面设计成不可用。
