# R21 真机测试说明

1. 安装 `hhy-r21-f049e67-test.apk`。包名为 `cc.orbexa.hhy.debug`，使用固定的 Hhy Staging Test V2 签名。
2. 登录已实名且具备广告主资格的 staging 测试账号，进入“我的”并打开红包活动管理。
3. 打开一个已通过预审核的红包活动，确认详情页展示服务端状态、金额、库存/统计、版本和已登记动作；验证暂停、恢复、关闭的状态和版本冲突提示。
4. 进入“提高红包金额”，填写合法的新增剩余单价，核对服务端返回的本金、服务费、最终金额、报价版本和支付渠道；确认页面固定底部主操作不裁切、不重叠。
5. 在允许的测试支付环境创建加价订单，确认不可退款协议清晰；重复点击或网络重试不得产生重复订单，历史报价和历史订单不得被改写。
6. 分别验证非法金额/活动状态、过期版本、无广告主权限、离线恢复和关闭后再次操作的拒绝路径。
7. 记录手机型号、Android 版本、账号、测试时间、每一步结果、requestId 和异常截图；真实支付回调仅使用项目所有者指定的测试渠道。
