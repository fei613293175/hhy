# R21 功能清单

- 红包付款激活：服务端报价版本、支付订单、不可退款协议和幂等订单创建。
- 提高剩余单价：基于当前活动版本创建差额报价与 `INCREASE` 订单，金额和版本由服务端锁定。
- 金额版本：提高金额会追加活动版本和报价事实，不修改历史报价或已创建订单。
- 生命周期：支持无限次暂停、恢复和关闭；版本冲突、非法状态和重复请求按契约拒绝或幂等返回。
- 运营数据：活动详情和 analytics 返回服务端真实状态、库存/金额摘要、报价及订单上下文。
- Android `SCR-RP-ADV-005`：活动详情、状态统计、已登记动作和固定底部操作区。
- Android `SCR-RP-ADV-006`：提高红包金额的活动上下文、本金/服务费/最终金额、支付协议和主操作。
- Backend / database：红包活动、版本、报价、订单、库存、账本、统计和 outbox 的事务不变量与审计链路。
- 可观测性：R21 业务事件、日志/指标和告警检查随 Backend CI 通过。
