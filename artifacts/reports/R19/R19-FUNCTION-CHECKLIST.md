# R19 完整功能清单：道具与曝光层级

版本：R19；APK 源码 Commit：`706a6f29d2469ad601bfe207348764315d713271`

## Android 用户端

- [x] “我的”页显示独立“道具中心”，提供“我的道具”和“道具商城”入口。
- [x] 道具商城读取已上架商品，支持分页、排序、状态和关键词条件。
- [x] 商品展示四类道具、普通价、会员价、有效时长、适用范围和可购买状态。
- [x] 购买链路提交 `skuId/quantity/paymentChannel`，遵循服务端报价、订单和幂等规则。
- [x] 我的道具展示库存、状态、有效期、配置摘要和版本号。
- [x] 使用链路支持刷新、置顶、头条、变色，选择目标内容并确认执行或排期。
- [x] 零库存、过期、不可用状态、版本冲突和离线错误均有明确阻止或恢复提示。

## 管理后台

- [x] `ADM-PROP-001` 道具商品列表支持四类道具查询、筛选和状态统计。
- [x] 支持创建道具商品，并在单事务中创建商品、SKU、道具定义和绑定关系。
- [x] 支持修改名称、普通价、会员价、时长、适用范围和状态，带版本冲突保护。
- [x] 支持上架、下架；无 `prop.manage` 权限时隐藏写操作。
- [x] `ADM-PROP-002` 支持资源位容量、状态和排期查询/配置，写操作受 `prop.slot.write` 控制。
- [x] `ADM-PROP-003` 提供只读执行日志、结果、内容、过期时间和错误摘要。
- [x] 创建/修改弹窗在 1440x900 及窄视口内可滚动，头部与提交区固定且无重叠。

## 服务端、数据库与契约

- [x] 客户端 4 个、管理端 5 个冻结 API 均已实现并纳入契约测试。
- [x] 道具商品、SKU、库存、曝光权益、刷新记录、头条资源位/排期、主题和执行日志具备持久化模型。
- [x] 实现归属校验、幂等、乐观锁、事务回滚、权限、审计和稳定错误码。
- [x] 实现叠加、冷却、每日限额、容量冲突、自动执行和业务统计指标。
- [x] 线上 API 路由已存在；未登录请求正确返回 `401 Unauthorized`，不再是接口缺失。
