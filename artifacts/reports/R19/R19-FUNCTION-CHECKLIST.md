# R19 功能清单：道具与曝光层级

版本：R19 / `b054642c`；对应 APK：`r19-entry-fix-30930316181`

## 用户端 Android

- [ ] “我的”页第二行显示“我的道具”和“道具商城”两个可点击入口。
- [ ] 道具商城（SCR-PROP-001）：读取商品、分页/排序、显示价格与可购买状态。
- [ ] 购买道具：提交订单，按服务端返回显示成功或失败，不重复扣款。
- [ ] 我的道具（SCR-PROP-002）：查看库存、状态、有效期和可使用条件。
- [ ] 使用道具（SCR-PROP-003）：选择内容、确认使用，覆盖刷新、置顶、头条、变色四类道具。
- [ ] 业务规则：库存必须为正且道具为 AVAILABLE 才可使用；版本冲突提示刷新；离线保留当前输入并允许重试。

## 管理端

- [ ] 道具商品（ADM-PROP-001）：查看四类道具商品、价格、时长、状态；无 `prop.manage` 时不显示写操作。
- [ ] 资源位与排期（ADM-PROP-002）：查看资源位容量与排期；创建操作按 `prop.slot.write` 权限控制。
- [ ] 执行日志（ADM-PROP-003）：查看执行结果、内容和过期时间；日志只读，不暴露原始传输状态。
- [ ] 权限、版本号、审计和幂等策略由服务端状态机统一约束。

## 服务端与数据

- [ ] 9 个冻结 API：客户端 4 个、管理端 5 个。
- [ ] 道具商品、SKU、用户库存、曝光权益、刷新记录、头条排期、执行日志及系统配置迁移和事务一致性。
- [ ] 叠加、去重、冷却、每日限额、资源位容量、自动执行和统计指标。
