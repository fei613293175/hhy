# SCR-FAV-001 我的收藏视觉施工规格

## 来源

精确面板 `B08/P07`。字段、分页、取消收藏动作和导航仅来自冻结 `SCR-FAV-001` 页面规格。

## 强制结构

1. 顶栏标题“我的收藏”，返回动作和内容统计保持稳定，不出现技术筛选项。
2. 列表卡片延续 B08/P07 的真实内容缩略图、类型、标题、发布者摘要和辅助状态层级；缺失媒体使用中性占位，不伪造图片。
3. 整卡进入对应真实详情；取消收藏是独立可聚焦动作，成功后局部移除并保持滚动位置。
4. 下拉刷新、追加加载、局部失败和只读缓存均保留已加载内容，不使用整页闪烁替换。
5. 空状态保留页面标题和导航，只提供文档允许的返回或浏览入口。

## 验收重点

卡片密度、图片比例、文字层级、分隔节奏和收藏动作的视觉位置应肉眼接近 B08/P07；不得把“我的发布”或“订单”字段混入收藏页。
