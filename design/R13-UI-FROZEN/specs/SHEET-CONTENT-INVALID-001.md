# SHEET-CONTENT-INVALID-001 联系方式失效反馈视觉施工规格

## 来源

- 失效语境：B03/P08 内容下架/失效页面的警示层级。
- 面板结构：B07/P07 举报用户底部面板的原因选择、说明输入和主次动作。
- 业务字段：仅使用冻结 `reasonCode`、可选 `description`、目标 ID 和幂等请求头。

## 首屏结构

1. 来源详情页保持在遮罩下方，面板标题“联系方式失效反馈”，说明提交目的与影响，不泄露高敏联系方式。
2. 原因选项使用清晰的单选行或选择卡；显示文案由受控枚举映射，不直接显示技术 `reasonCode`。
3. 详细说明为可选多行输入，展示字数边界和就地校验；禁止在日志、截图测试数据或错误文案回显真实高敏内容。
4. 提交前按动作合同执行二次确认；提交期间锁定同资源写操作并保留输入。
5. 成功后回传结果并关闭；400/403/409/422/429/500 与离线状态均在面板内提供明确恢复路径。

## 禁止项

- 不复用 B03/P08 的“下架”管理动作或后台权限。
- 不增加附件、客服聊天、赔付、审核进度或其他未登记功能。
- 不把技术 ID、HTTP 状态码或内部原因码作为用户主文案。
