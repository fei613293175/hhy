# SCR-PROP-003 使用道具视觉施工规格

## 精确来源

- 复用 B11/P07 的使用确认弹层：背景上下文、顶部标题与关闭、道具摘要、目标内容选择、数量步进器、计划生效时间和固定底部取消/确认操作。
- 所有业务输入来自页面字段目录：`id`、`targetContentId`、`scheduledAt`、`expectedVersion` 和 `X-Idempotency-Key`。

## 区域顺序

1. 返回/关闭与标题“使用道具”，保留来源页焦点。
2. 道具摘要：真实 `propType/name/status/quantity/expiresAt/configuration/version`，不显示 B11 示例图片或数量。
3. 目标内容选择：只显示当前用户可访问且由服务端返回的内容摘要；不能把任意 ID 当作有效内容。
4. 数量和计划生效时间：遵循服务端状态机、额度、24 小时权益和排期冲突；本地只做字段格式校验。
5. 固定底部取消/确认；确认前显示影响范围和二次确认条件，提交锁定同资源操作。
6. 编辑、脏状态、验证中、提交中、成功、错误、冲突和离线状态不得静默丢失输入；409 必须重新加载差异，禁止盲目覆盖。

## 过滤边界

- 不在客户端计算有效期、叠加层级、排期冲突、刷新次数或价格；不复制 P07 的示例内容与时间。
- 成功只依据服务端响应，清理一次性输入并刷新库存/曝光权益/执行日志关联区域。
