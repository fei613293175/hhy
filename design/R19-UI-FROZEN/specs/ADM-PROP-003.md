# ADM-PROP-003 执行日志后台视觉施工规格

## 精确来源

- 后台无精确效果图，采用后台 Design Token、`ADM-LIST`、`CMP-ADM-001/002/004/005` 和执行日志运营目录冻结。
- 目标是可审计的高密度只读日志表格；不把执行结果重画成营销卡片。

## 区域顺序

1. 标题“执行日志”、说明、刷新和真实统计。
2. URL 同步筛选 `page/pageSize/cursor/status/keyword/sort`，默认 `createdAt:desc`。
3. 只读日志表格：道具类型/名称、目标内容、执行时间、结果、错误摘要、版本和关联业务标识；敏感字段脱敏。
4. 首屏、空、刷新、翻页/局部失败、无权限、离线恢复和 requestId 定位入口。
5. 只在页面目录允许且具备权限时显示关联详情；任何重试/修改必须走登记动作和服务端状态机，不在日志页发明按钮。
6. 日志加载失败保留筛选上下文；禁止把原始 payload、IP、设备指纹或 SecretRef 直出。

## 禁止项

- 无批量写、无删除日志、无客户端重算结果、无技术状态码直接展示；审计字段最小化且可追溯。
