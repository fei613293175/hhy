# ADM-PROP-002 资源位与排期后台视觉施工规格

## 精确来源

- 后台无精确效果图，采用后台 Design Token、`ADM-LIST`、`CMP-ADM-001/002/004/005` 和资源位运营目录冻结。
- 重点是资源位容量、状态和排期冲突的扫描密度；不使用移动端 B11 卡片布局。

## 区域顺序

1. 标题“资源位与排期”、说明、刷新和真实统计。
2. URL 同步筛选 `page/pageSize/cursor/status/keyword/sort`，默认 `createdAt:desc`。
3. 资源位表格与排期摘要：只展示 `headline_slots`/`headline_slot_bookings` 服务端事实、状态、容量、时间窗、冲突提示和版本。
4. 首屏、空、刷新、翻页/局部失败、无权限和离线恢复。
5. `prop.slot.write` 才显示“创建资源位”；提交前展示页面、资源位、容量、时间窗、冲突影响、原因和服务端版本，成功后刷新列表。
6. 409 重载差异，422 保留输入；排期冲突不可被前端静默覆盖。

## 禁止项

- 不增加批量排期、免费刷新、隐式扩容或未登记审批；冲突、容量与生效时间只信任服务端。
