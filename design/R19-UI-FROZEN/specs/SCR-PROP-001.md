# SCR-PROP-001 道具商城视觉施工规格

## 精确来源

- 复用 B11/P04 的道具商城面板：顶部返回与标题、促销区、分类标签、两列商品网格和底部五栏导航。
- B11 的商品图、示例价格、库存数字、日期、徽章和“我的道具”入口只作为视觉参考，全部替换为服务端 `PropResource` 与配置事实。

## 区域顺序

1. 返回、标题“道具商城”和已登记的“我的道具”入口。
2. 只显示真实道具能力的横幅或说明，不发明折扣、广告承诺或未登记入口。
3. 四类道具的状态/筛选区；筛选映射 `page/pageSize/cursor/status/keyword/sort`，变化重置分页。
4. 两列稳定商品网格；展示 `id`（仅必要上下文）、`propType`、`name`、`quantity`、`status`、`expiresAt`、`configuration` 和 `version`，购买使用 `skuId/quantity/paymentChannel`。
5. 空、加载、刷新、翻页、局部失败、无权限、离线与错误恢复保持同一结构；写操作离线禁用。
6. 购买确认使用标准弹层，最终金额/权益只取服务端，提交期间复用同一幂等键并刷新受影响区域。

## 过滤边界

- 不复制 B11/P04 的虚构商品、金额、图片、数量、日期、红点、会员身份或“免费”语义。
- 不在客户端计算价格、权益、有效期或叠加结果；技术状态码、requestId 和数据库 ID 不作为营销文案。
