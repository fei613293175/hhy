# SCR-PROP-002 我的道具视觉施工规格

## 精确来源

- 复用 B11/P06 的“我的道具”面板：返回与标题、状态标签页、紧凑库存列表、每行状态/有效期和右侧动作。
- 列表内容严格使用 `GET /api/v1/me/props` 的 `PropResource`；B11 的示例道具、数量和日期不进入产品。

## 区域顺序

1. 返回、标题“我的道具”和可登记的使用记录入口。
2. 状态/筛选标签映射 `status/keyword/sort`，筛选变化重置 `page/pageSize/cursor`。
3. 列表行稳定展示 `propType`、`name`、`quantity`、`status`、`expiresAt`、必要配置摘要与服务端 `version`；有效道具才显示“使用”。
4. 首屏骨架、空态、下拉刷新、翻页尾部加载、局部失败、无权限、离线缓存和全页错误均保留列表骨架。
5. 点击使用保存来源资源和最新 `version`，进入 SCR-PROP-003；成功后只刷新受影响库存与曝光状态。

## 过滤边界

- 不展示 B11 的示例数量、日期、成功次数、技术枚举或未登记的“使用中/已过期”业务解释。
- 不允许客户端在过期、叠加或可用性上自行推断；入口由服务端状态与动作目录共同决定。
