# ADM-PROP-001 道具商品后台视觉施工规格

## 精确来源

- 后台无精确效果图，采用后台 Design Token、`ADM-LIST`、`CMP-ADM-001/002/004/005` 和 `admin_page_operation_specs.csv` 冻结。
- 主内容为紧凑运营表格，不复用 B11 移动端商品卡；表格主区独立滚动，操作列稳定可达。

## 区域顺序

1. 标题“道具商品”、说明、刷新和权限内真实统计。
2. URL 同步的 `page/pageSize/cursor/status/keyword/sort` 筛选；查询/重置明确。
3. 表格列按目录：ID/道具类型/名称/数量/状态/过期时间/配置/版本；敏感值默认脱敏。
4. 首屏、空、刷新、翻页/局部失败、无权限、离线状态和分页恢复。
5. 仅 `prop.write` 显示行级“修改道具”；编辑器只提交 `reason/expectedVersion/payload`，确认框展示目标、影响、版本和审计入口。
6. 409 显示差异并重载，422 保留输入，成功更新当前行和统计，不能只显示 Toast。

## 禁止项

- 无批量写、无客户端生成配置、无技术枚举直出、无盲目覆盖版本；数据字段和按钮不得超出目录。
