# SCR-LIST-001 项目列表视觉施工规格

- 权威页面合同：`docs/02-ui/page-specs/android/SCR-LIST-001_项目列表.md`
- 精确视觉面板：`B02/P05`
- Token：`design/tokens/hhy_design_tokens_v1.2.2.json`
- 状态：`APPROVED_FOR_CONSTRUCTION`

## 固定结构

1. 56dp 标准返回顶栏，标题“项目”，不得增加效果图中的虚构排序入口。
2. 16dp 页面左右边距；顶栏后先显示 20sp 页面标题和 14sp 事实说明，再显示横向排序 Chip。
3. 项目卡片宽度占可用宽度，圆角 16dp，卡片间距 12dp；有真实媒体时使用 112dp 媒体区，无媒体时不得生成占位业务图片。
4. 卡片正文依次为：标题与真实状态、摘要、分类/地区标签、发布者与真实统计。缺失字段隐藏或显示合同允许的空状态，不得补写示例金额、人数、融资阶段或收益。
5. 页面右下主动作只允许“发布项目”；列表项整体进入详情。分页仅在服务端 `hasMore=true` 时显示。

## 状态

- LOADING：3 张与最终卡片轮廓一致的骨架卡。
- EMPTY：明确无项目、重新加载，不展示样例项目。
- OFFLINE/ERROR/FORBIDDEN：稳定商业文案、返回与重试；请求编号只在错误恢复区按合同条件显示。
- CONTENT：只展示 `contentType=PROJECT` 且接口返回的条目，按 ID 去重追加。

## 肉眼验收

- 对照 B02/P05 核查卡片纵向密度、标题/摘要/标签/底部统计四级层次、品牌蓝与白色卡片质感。
- Token 合规或能滚动不等于通过；最终 PASS 必须绑定候选截图并由 AI 逐图判断。
