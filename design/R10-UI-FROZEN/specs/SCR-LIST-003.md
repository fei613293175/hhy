# SCR-LIST-003 群聊列表冻结视觉规格

- 权威页面合同：`docs/02-ui/page-specs/android/SCR-LIST-003_群聊列表.md`
- 精确效果图：`design/effect-previews/B02/HHY_B02_8PAGE_UI_REFERENCE.png` 的 `P07`
- Token：`design/tokens/hhy_design_tokens_v1.2.2.json`
- 批准来源：`CR-0266`、`CR-0278`
- 状态：`EXACT`

本规格用效果图决定视觉建模，用页面合同和接口决定真实业务。效果图中的示例群名、头像、人数、标签和统计不得成为生产默认数据。

## 固定结构

1. 56dp 返回顶栏，标题“群聊”；页面背景 `#F5F7FA`，左右边距 16dp。
2. 顶部品牌引导区保持 P07 的群聊主题、标题与说明层级；不得改成普通标题加裸列表。
3. 排序区使用紧凑 FilterChip；变化后重置 cursor。列表卡圆角 16dp、内边距 16dp、卡间距 12dp。
4. 卡片保持 P07 的群聊品牌块、名称、两行摘要、平台/规模/地区标签、发布者与真实浏览统计层级；无媒体时使用品牌中性群聊标识，不生成虚构二维码或群头像。
5. “发布群聊”为显式主动作；加载、空、失败、分页均使用完整业务状态，不显示接口名、请求编号或内部枚举。

## 肉眼验收

- 首屏必须同时具备品牌引导、排序和多层群聊卡，不得退化成标题加裸列表。
- 所有群名、说明、平台、规模、地区、发布者和统计来自服务端；未知编码显示受控中文兜底。
- 最终候选截图由 AI 与 P07 逐项对照后才能登记 PASS。
