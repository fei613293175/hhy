# ADM-ORDER-001 订单管理视觉施工规格

## 商业后台骨架

- 复用 `ADM-LIST` 与后台视觉设计系统：固定左侧导航，右侧主内容独立滚动，禁止菜单滚动带动主区。
- 主内容最大宽度 1600px；页面内边距桌面 24px、窄屏 16px；卡片圆角 12px；表格行高 52–60px。
- 页面标题 24px/600，统计主值 24–28px，表头 13px/600，表格正文 14px，辅助信息 12px。

## 信息结构

1. 标题区：订单管理、只读能力说明、最后刷新时间。
2. 统计区：总订单数及服务端能够真实返回的状态计数；没有聚合接口时不展示虚构指标。
3. 筛选区：订单号/关键词、订单状态、排序与重置；筛选写入 URL。
4. 表格：订单号、用户ID、类型、状态、应付、实付、创建时间和操作；重要列固定且不允许隐藏。
5. 详情抽屉：订单项、完整价格快照、不退款证据、时间和版本；只读且保留来源筛选与滚动位置。
6. 分页、空状态、首屏错误、局部刷新失败、无权限和离线提示均在主区就地呈现。

## 管理边界

- 本页只有订单读取与详情查看，不提供批量写、退款、余额修改、支付处理、客服或删除。
- 金额、状态和时间只能来自显式 `OrderResource`；技术枚举必须中文化，ID保持可复制但不使用英文标题。
- 导出入口只有在真实 `export.create` 能力实现并登记后才可出现；当前不得用假按钮占位。
