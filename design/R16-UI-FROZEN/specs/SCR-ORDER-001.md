# SCR-ORDER-001 订单列表视觉施工规格

## 来源与密度

- 精确参考 B08/P04；保持标题、紧凑筛选、纵向订单卡片和详情入口的层级。
- 页面水平边距 16dp，区域间距 12–16dp，卡片内边距 14–16dp，卡片圆角 14dp。
- 页面标题 22sp/半粗，订单号与状态 12–13sp，订单项 15–16sp，金额主值 18sp/半粗，辅助时间 12sp。

## 卡片结构

1. 顶部显示“我的订单”和真实结果数；筛选只使用服务端状态，不增加待发货、退款等不存在的分类。
2. 每张卡片依次显示订单号、中文状态、订单项摘要、订单类型、应付/实付金额、不退款确认状态与创建时间。
3. 多订单项最多展示两行摘要，其余显示真实数量汇总；无订单项时显示“订单明细暂不可用”，不得编造商品。
4. 整张卡片进入订单详情；不提供联系客服、立即支付、退款、删除或再次购买。
5. 骨架、空状态、刷新、翻页失败、离线缓存和全页错误必须保持相同版式，不得退化为裸文本。

## 反虚构边界

- 示例订单号、商品名、图片、金额、时间、状态和按钮均不得写入正式夹具或代码。
- `userId`、`version`、requestId 和技术枚举不展示；`ORDER_STATUS`使用统一中文映射。
- 金额全部来自 `OrderResource.priceSnapshot` 与 `paidAmountCent`，单位由分格式化为人民币。
