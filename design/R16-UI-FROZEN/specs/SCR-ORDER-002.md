# SCR-ORDER-002 订单详情视觉施工规格

## 来源与布局

- 复用 B08/P04 的品牌色、圆角卡片、状态标签、金额层级和时间信息密度，不复制示例业务。
- 顶栏 56dp；页面水平边距 16dp；卡片内边距 16dp；分区间距 12–16dp；底部保留系统安全区。
- 标题 20–22sp，分区标题 16sp/半粗，正文 14–15sp，关键金额 22sp/半粗，辅助信息 12sp。

## 固定分区

1. 状态摘要：订单号、中文状态、订单类型和创建时间。
2. 订单项：逐项显示真实名称、数量、单价和小计；无 SKU 的服务项允许显示服务端快照名称。
3. 价格明细：原价、优惠、服务费、应付和实付，金额来源不得互相代替。
4. 不退款证据：确认状态、协议版本和确认时间；历史数据缺失时明确显示“历史订单未记录”，不得标记为已确认。
5. 时间信息：创建时间与支付时间；未支付时不显示虚构支付时间。

## 状态与动作

- 只读详情不提供支付、退款、联系客服、物流、发票或再次购买。
- 加载、缓存过期、404、无权限、离线和错误均有结构化状态；缓存状态禁止衍生写操作。
- `userId`、`version`、requestId、规则版本和技术枚举不面向普通用户展示。
