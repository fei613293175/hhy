# SHEET-CHAT-001 发送联系方式视觉施工规格

## 来源

## 区域与状态

1. 从私聊页受信任入口打开底部面板，背景会话保持可识别但不可操作。
2. 可选择手机号、微信、QQ、邮箱和其他联系方式；至少选择一项，其他类型必须提供短标签。
3. 每项值就地校验并明确敏感提示；备注可选、最多 200 字，不写入日志或埋点。
4. 底部固定取消和“发送联系方式”操作；提交时锁定当前意图，失败保留输入，成功回传新消息并关闭。
