## 区域与状态

1. 标题为“举报聊天”，说明举报范围和证据用途，不展示内部会话 ID。
2. 原因使用受控枚举映射为用户文案；说明可选，消息证据和媒体证据按冻结数量与权限选择。
3. 提交前二次确认目标与证据范围；expectedVersion 和幂等键由网络层维护。
4. 提交中保留输入并锁定按钮；冲突时刷新证据版本后要求再次确认；成功后清除敏感草稿并关闭。
