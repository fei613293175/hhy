## 区域与状态

1. 顶栏展示真实对方头像、昵称和可用业务状态；返回、举报、拉黑、删除使用共享矢量图标与真实导航栈。
2. 消息流按服务端顺序展示 `TEXT`、`IMAGE`、`CONTENT_CARD`、`CONTACT_CARD`；不同类型使用明确可辨的气泡或卡片，但不额外创造点赞、转账、红包、语音或视频入口。
3. 图片支持加载、失败占位、预览和权限允许时保存；内容卡展示真实标题、类型和封面；联系方式卡只展示发送者明确选择的字段与备注。
4. 输入区保持稳定高度，提供文本、图片、内容和联系方式入口；发送中、失败重试、已送达、已读、离线、限频和拉黑禁发均有就地状态。
5. 首屏加载失败保留顶栏与输入区骨架；历史翻页失败保留已加载消息；恢复网络后按服务端游标去重合并。

## 过滤

- 过滤 P02/P04 的示例用户、项目、金额、红包领取按钮、人数和虚构文案。
- `requestId`、幂等键、clientMessageId、版本、服务端序列和资源 ID 仅供网络层诊断与去重，正式 UI 不展示。
