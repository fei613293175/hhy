| 页面 | 视觉合同 | 过滤与补充 |
| --- | --- | --- |
| SCR-CHAT-001 | B07/P01 | 保留标题、搜索、真实会话行、时间与未读；过滤通知/公告/客服/系统快捷区及示例数据 |
| SCR-CHAT-002 | 补充规格，复用 B07/P02、P04 | 补齐四类消息、发送状态、离线、失败重试、图片预览和拉黑禁发 |
| SHEET-CHAT-001 | 补充规格，复用 B07/P03 | 只保留联系方式选择语言，过滤项目与快捷语；补字段选择、备注和提交状态 |
| SHEET-CHAT-002 | 补充规格，复用 B07/P07 | 补消息证据、媒体证据、二次确认和错误恢复 |
| DIALOG-CHAT-BLOCK-001 | 补充规格，复用 B07/P07、P08 | P07 提供弹层结构，P08 只提供拉黑影响与结果语义，不冒充确认框 |
| DIALOG-CHAT-DELETE-001 | 补充规格，复用 B07/P07 | 明确仅删除当前用户会话视图，不删除对方记录 |
