# ADM-MEMBER-001 会员 SKU 后台视觉施工规格

## 基线

- 复用当前后台 `page-heading`、筛选栏、可横向滚动数据表、分页、状态标签和标准 modal 视觉语言；不得把 `TOKENS_ONLY` 当作自由设计许可。
- 主内容独立滚动；桌面表格保持紧凑扫描密度，窄视口允许横向滚动，操作列稳定可达。

## 区域顺序

1. 标题“会员 SKU”、说明、刷新；只显示真实汇总。
2. URL 同步的状态、关键词和排序筛选；查询与清除动作明确。
3. SKU 表格：SKU、名称、状态、期限、价格、权益摘要和版本；技术 ID 仅在必要上下文展示。
4. 分页与首屏、空、刷新、翻页失败、无权限状态。
5. 行操作打开“价格和期限”或“权益配置”弹层；展示目标、影响、服务端版本和明确确认文案。
6. 409 显示差异并重新加载；422 保留输入；成功更新当前行与汇总，不只显示 Toast。

## 禁止项

- 无批量写、无客户端生成权益字段、无盲目覆盖版本、无技术枚举直出。
- 不使用 B11 的移动端会员卡替代后台表格，但色彩与 Pro 标识保持同一品牌语义。
