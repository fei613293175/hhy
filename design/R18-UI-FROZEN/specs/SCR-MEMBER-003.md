# SCR-MEMBER-003 会员升级视觉施工规格

## 视觉来源

- B11 没有独立升级页；复用 `B11/P03` 的 Pro 主卡和纵向权益层级，结合 P01 套餐卡建立补差升级页。
- 当前会员与目标套餐必须在首屏形成清晰对照；剩余价值和应付补差使用独立金额层级，不混入奖励余额。

## 区域顺序

1. 返回与标题“升级 Pro”。
2. 当前 Pro 摘要：真实套餐、有效期、付费剩余价值；赠送分段只按合同展示，不冒充可抵扣金额。
3. 目标 SKU 选择：只展示允许升级的月/季/年 SKU；当前 SKU 和不可用目标明确禁用。
4. 服务端报价卡：原价、可转换剩余价值、应付补差、报价有效期和保留赠送天数策略。
5. 协议与支付方式；报价过期、版本冲突或状态变化时禁用提交并重新报价。
6. 固定主操作显示服务端应付金额；创建升级订单后进入正式支付/查单流程。

## 过滤边界

- 不显示“团队长 Pro”、团队加成、课程或示例折扣。
- 禁止客户端按天数自行折算、四舍五入或延长有效期；所有金额与时间以服务端报价为准。
