# SCR-MEMBER-001 会员中心视觉施工规格

## 精确来源

- 精确参考 `B11/P01`，保留会员中心的顶部主卡、权益摘要和套餐区层级。
- 页面水平边距 16dp，区块间距 12–16dp；主卡使用品牌蓝、12–16dp 圆角和紧凑状态信息；套餐为稳定三列，不因价格长度改变布局。

## 区域顺序

1. 返回、标题“会员中心”和已登记的会员规则入口。
2. 当前会员主卡：统一显示 `Pro`、真实状态、起止时间/有效期；未开通时仍保持同一主卡结构并显示真实未开通状态。
3. 权益摘要：最多四项真实权益摘要；进入完整权益页，不展示 B11 示例次数。
4. 套餐区：月、季、年 SKU 使用同层级选择卡，显示服务端名称、价格、期限和状态；不可用 SKU 保留位置并说明原因。
5. 主操作：未开通进入购买，已开通且允许升级时进入升级；不得根据客户端猜测状态。
6. 骨架、空、局部失败、离线缓存和全页错误沿用上述区域，不退化为裸文本。

## 过滤边界

- 不实现普通会员、商家会员、团队长 Pro 多身份；不复制示例价格、日期、权益次数和底栏红点。
- `id`、`version`、requestId、游标和技术状态码不进入正式可见 UI。
