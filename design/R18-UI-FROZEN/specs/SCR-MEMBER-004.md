# SCR-MEMBER-004 会员权益明细视觉施工规格

## 视觉来源

- 复用 `B11/P02` 与 `B11/P03` 的 Pro 主卡、纵向权益行和右侧真实值层级。
- 页面水平边距 16dp；权益分组卡间距 12dp；每行图标槽、名称、说明和值保持稳定对齐。

## 区域顺序

1. 返回与标题“Pro 权益”。
2. Pro 状态摘要：公开标识、真实状态和有效期。
3. 当前购买快照的权益清单；按服务端顺序或冻结分组展示 code 对应的人类名称、说明、值和单位。
4. 无权益、部分加载失败、离线缓存和已过期状态保持清单骨架与恢复入口。
5. 只在合同允许时提供返回会员中心或升级入口，不在权益行内发明操作。

## 过滤边界

- 不展示商家/团队长专属身份，不复制示例曝光、推荐、课程或数据看板承诺。
- 后台后来修改 SKU 权益不得覆盖历史购买快照；无真实使用量时不显示进度条或次数。
