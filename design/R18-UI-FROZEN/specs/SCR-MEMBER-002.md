# SCR-MEMBER-002 会员购买确认视觉施工规格

## 视觉来源

- B11 没有独立结算页；复用 `B11/P02` 的顶部 Pro 卡、纵向权益清单和底部套餐层级，并按 `MOB-CHECKOUT` 补齐结算区域。
- 页面水平边距 16dp；金额摘要与权益卡间距 12dp；固定主操作位于安全手势区上方，不遮挡协议和支付方式。

## 区域顺序

1. 返回与标题“确认开通 Pro”。
2. 所选 SKU 摘要：统一 Pro 标识、真实套餐名、期限、服务端价格与状态。
3. 权益清单：展示购买时将快照的真实权益，采用 P02 的单行图标、名称和值层级。
4. 费用与协议：最终金额只取服务端响应；协议未确认时主操作禁用。
5. 支付方式：只展示服务端允许的方式；未知支付结果进入查询态，不在客户端宣告成功。
6. 固定主操作显示最终金额和明确命令；提交中锁定重复点击，同一意图复用幂等键。

## 过滤边界

- 不显示“商家会员”、示例折扣、划线价、赠送天数或未登记权益。
- 不信任路由金额，不在客户端计算优惠，不增加取消会员、自动续费或退款承诺。
