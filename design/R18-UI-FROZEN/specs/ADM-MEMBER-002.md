# ADM-MEMBER-002 用户会员后台视觉施工规格

## 基线

- 复用当前后台标题、统计、筛选、数据表、分页、详情抽屉/弹层和状态恢复视觉语言。
- 数据密度以重复运营扫描为目标；金额、期限、状态和版本列对齐，敏感原值默认不可见。

## 区域顺序

1. 标题“用户会员”、说明、刷新和权限内真实统计。
2. 状态、关键词、创建时间/排序筛选写入 URL。
3. 用户会员表格：用户安全标识、统一 Pro、SKU、状态、起止时间、付费值、剩余值和版本。
4. 行详情按概览、业务数据、状态历史、关联对象和操作审计分区。
5. 仅具备 `membership.grant` 时显示人工赠送；弹层展示目标、SKU/期限、原因、影响和服务端版本，成功后刷新对应行。
6. 首屏、空、局部失败、无权限、离线和版本冲突保持页面上下文与恢复动作。

## 禁止项

- 不实现多会员身份、余额直接修改、默认批量赠送或未登记导出字段。
- 手机号、身份证、支付账号、IP、设备指纹和 SecretRef 默认脱敏；无字段权限时不泄露资源存在性。
