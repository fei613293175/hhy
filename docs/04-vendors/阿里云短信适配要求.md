# 阿里云短信适配要求

## 固定用途

- 登录验证码 `LOGIN`
- 注册验证码 `REGISTER`
- 重置密码验证码 `RESET_PASSWORD`
- 后续关键安全通知可另建模板

## 工程要求

- 通过 `SmsProvider` 接口适配，不在业务层直接依赖 SDK。
- AccessKey、Secret、签名和模板 Code 通过服务器 Secret 注入。
- App/H5 不得持有阿里云密钥。
- 每次发送保存业务场景、手机号、模板、供应商消息 ID、结果、IP、设备和规则版本。
- 发送前验证一次性安全挑战。
- 支持通道错误映射、超时、有限重试、回执查询和熔断。
- 正式模板和签名由用户后续提供，不阻塞工程骨架。
