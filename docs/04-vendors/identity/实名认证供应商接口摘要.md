# 实名认证供应商接口摘要

来源：用户上传的《输出内容(1).txt》及对应截图。

## 接口

- POST `https://kzlive.market.alicloudapi.com/api/liveness/h5/token`
  - 创建活体 H5，Body 至少包含 returnUrl。
- POST `https://kzlive.market.alicloudapi.com/api/liveness/h5/result`
  - Body: orderNo，选填 hbId。
  - result=0 表示活体通过，返回 faceImageUrl。
- POST `https://sdfaceid.market.alicloudapi.com/face_id_card/check`
  - Body: idcard、name，以及 image 或 url 二选一。
  - 1001 同一人；1002 不确定；1003 不同人；1004 无法识别。

## 安全约束

- APPCODE 只保存在服务端。
- 人脸照片由后端下载后存入 Cloudflare R2 私有区。
- App 只查询平台实名状态，不直接调用供应商结果接口。
