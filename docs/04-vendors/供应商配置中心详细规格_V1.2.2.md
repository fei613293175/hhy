# 合伙云 Pro 供应商配置中心详细规格 V1.2

## 1. 目标

阿里云短信、Cloudflare R2、阿里云 OSS、实名认证、彩虹易支付、支付宝企业付款等第三方能力不得写死在代码或聊天中。后台配置中心必须提供**定义、密钥/证书安全保存、版本、校验、连接测试、双人激活、回滚和审计**。

## 2. 配置安全

- Secret、私钥和证书使用信封加密；主密钥仅由服务器环境变量或 KMS 提供。
- 保存成功后任何 API 和页面不得返回秘密原文，只显示“已配置”、末四位、指纹或有效期。
- 证书和私钥上传至私有对象存储，只有受控后台服务和 CI 签名步骤可取用。
- 支付、出款、正式签名、生产存储切换必须双人复核。
- 配置变更生成不可覆盖版本；激活时记录申请人、复核人、测试结果、时间和 IP。

## 3. 供应商分组

### 3.1 阿里云短信

后台字段至少包括 Region、Endpoint、AccessKey ID、AccessKey Secret、短信签名、登录/注册/重置密码/安全通知模板 Code、验证码有效期、冷却、手机/IP/设备限流、超时和重试。必须支持连接测试和向指定测试手机号发送测试短信。正式模板资料可在 R32 收尾，但适配器和后台在 R03/R02 完成。

### 3.2 对象存储

支持 Cloudflare R2 与阿里云 OSS。按 `public_media/private_kyc/private_chat/audit_evidence/apk_release/backup` Scope 单独绑定供应商、Bucket 和公开域名。支持连接测试、上传/下载/删除测试、短时私有预览、迁移任务、断点续传和切换回滚。

### 3.3 实名认证

配置 APPCODE、活体 Token 地址、结果地址、人脸比对地址、回跳、超时、轮询、最大尝试次数和结果码映射。AppCode只在服务端使用。活体成功后立即下载人脸图片并保存私有存储。原始接口资料位于 `docs/04-vendors/identity/`。

### 3.4 彩虹易支付

预留 Base URL、商户 ID、商户 Key、签名算法、支付渠道、回调 URL、同步返回 URL、超时、允许的 H5 Host/Scheme、主动查单和通道冲正。R17完成接口抽象、H5收银台和模拟契约；实际字段以用户后续提供文档在 R32 收尾。

### 3.5 支付宝企业付款

后台配置 AppID、商家 ID、应用私钥/证书、应用公钥证书、支付宝公钥证书、根证书、网关、回调、超时、查询策略和自动出款开关。证书通过文件上传，保存后只展示指纹和有效期。R24完成出款抽象和模拟流程；实际生产接入在 R32。

## 4. 后台页面和 API

页面：`ADM-CONFIG-002` 至 `ADM-CONFIG-008`。API：`/admin-api/v1/provider-configs*`、`/provider-certificates*`、`/domains*`。表：`provider_config_*`、`provider_certificates`、`domain_configs`、`storage_scope_bindings`。

## 5. 验收

- 未配置生产密钥时系统可在 Mock/Test Profile 工作，但生产环境启动必须门禁。
- 配置测试失败不得激活。
- 配置修改不影响历史订单/会员/奖励规则快照。
- 日志不得出现 Secret、身份证、人脸原图地址或私钥原文。
