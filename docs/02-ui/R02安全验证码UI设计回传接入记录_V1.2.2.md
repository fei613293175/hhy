1. 验证器通过后登记新的变更请求，审查所有可编辑文件差异；不得直接覆盖仓库。
2. 只合入批准的规格与效果图，冻结触发、关闭、重试、过期、刷新、成功自动续办和返回栈规则。
3. 依据最终规格替换 Android 当前临时内联挑战实现；初始页不得展示验证码或技术按钮。
4. 补齐 ViewModel/Compose UI/截图或语义测试，覆盖加载、错误、过期、刷新、并发防重、键盘、小屏、TalkBack和敏感日志。
