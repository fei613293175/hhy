# V1.2.2 管理后台页面与运营操作完整规格

## 1. 结论

管理后台现包含 **74 个页面**，其中包括登录/MFA、举报申诉、工单详情、统一会计、双人审批、风控规则模拟、通知治理、数据导出和管理员安全中心。所有页面已绑定标准模板、字段、状态、动作和运营操作规格。

## 4. 强制规则

- 筛选条件写入 URL，返回列表时必须恢复筛选、排序、页码和滚动位置。
- 高敏字段默认脱敏；查看原文需要字段权限、MFA会话升级、目的说明和访问审计。
- 资金、秘密、生产发布、永久处罚、高风险导出和规则激活必须使用不可变审批快照，申请人不得自审。
- 已过账账本、支付事实和出款事实禁止直接编辑；纠错必须创建反向交易或受控调整。
- 导出统一进入异步导出中心，不得在业务页面直接生成高敏文件。
- 审核、举报、申诉不允许批量作出最终决定；每个决定必须绑定证据、原因、版本和审计记录。
