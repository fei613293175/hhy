# V1.2.2 页面状态、错误恢复、深链与返回栈规范

## 状态来源

`catalogs/ui_page_states.csv` 是页面状态唯一事实源。状态必须是用户可感知的 UI 状态，而不是仅存在于 ViewModel/Store 的布尔变量。

## 错误分层

| 场景 | 页面行为 |
|---|---|
| 首屏失败 | 全页错误、稳定错误码、requestId、重试和返回 |
| 刷新失败 | 保留旧数据并标记可能过期，不清空页面 |
| 翻页失败 | 保留已加载项，列表尾部提供重试 |
| 局部模块失败 | 仅失败模块展示恢复入口 |
| 401 | 尝试允许的令牌刷新；失败后登录并保存安全原目标 |
| 403 | 显示无权限，不泄露资源是否存在；后台记录拒绝审计 |
| 404 | 进入资源不存在/下架状态并同步来源列表 |
| 409 | 加载最新 version 和差异，禁止盲目覆盖 |
| 422 | 展示业务规则原因并保留安全可保留输入 |
| 429 | 显示服务端重试时间，禁止客户端自行猜倒计时 |
| 500/网络 | 保留上下文、requestId 和人工重试；写操作不得自动重复 |
| 支付/出款未知态 | 查询平台订单/出款事实，不得直接再次扣款或出款 |

## 返回栈

- 详情返回来源列表时恢复筛选、排序、页码、滚动位置和已更新资源状态。
- 登录前保存原目标；认证成功后仅跳回白名单路由。
- 回跳页立即清理 URL 中的一次性 token/state，浏览器后退不得再次暴露。
- Sheet/Dialog 不允许外部深链；关闭后焦点回到触发控件。
- 底部导航根页面之间切换不叠加重复栈。

逐页规则见 `catalogs/ui_navigation_specifications.csv`。
