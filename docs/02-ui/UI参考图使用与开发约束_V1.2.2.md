# UI 参考图使用与开发约束 V1.2

## 核心结论

12 批组合效果图已经纳入项目，但它们的法律地位和工程地位是：

> **仅作为页面 UI 布局、视觉风格、信息层级和组件摆放参考，不是功能事实源。**

开发功能必须来自完整项目开发文档、业务规则、API 契约、数据库模型和测试用例。精确 UI 数值必须来自 Design Token 和页面规格。

## 冲突优先级

1. 完整项目开发文档
2. 已批准 Change Request / ADR
3. Design Token
4. 页面规格和组件规范
5. 屏幕—效果图绑定表
6. 12 批效果图
7. 开发者或 AI 推测

## Codex 禁止行为

- 根据效果图中的虚拟按钮新增功能。
- 根据效果图中的虚拟金额、会员类型、余额或文案修改业务规则。
- 因效果图没有画某功能而删除开发文档要求。
- 使用效果图像素写死所有高度和位置。
- 直接复制 AI 生成的错误中文。
- 在页面中自行创造未登记颜色、dp、sp、圆角和阴影。
- 将 B09 中的“充值/商豆”实现为用户充值钱包。
- 将 B11 中的多种会员身份实现为多套会员体系。
- 将 B01 中的第三方登录图标实现为微信/QQ/支付宝登录。

## 开发应还原的内容

- 页面区域顺序
- 信息主次层级
- 卡片形态
- 导航和按钮位置
- 表单区块组织
- 空状态、成功、失败、弹层的视觉关系
- 合伙云品牌色和统一组件语言

## 精确数值

固定值见 `design/tokens/hhy_design_tokens_v1.2.2.json`。包括：

- 页面左右边距 16dp
- 模块间距 20dp
- 卡片间距 12dp
- 卡片内边距 16dp
- 顶部导航 56dp
- 底部导航 64dp + 安全区
- 主按钮 48dp
- 输入框 52dp
- 卡片圆角 14–16dp（具体组件固定一种）
- 按钮/输入框圆角 12dp
- 页面标题 20sp/28sp
- 卡片标题 16sp/24sp
- 正文 14sp/22sp

页面不得从效果图重新估算这些数值。

## 已知视觉偏差

- B01：图中以短信登录为主且出现第三方登录；真实产品默认手机号+密码登录，不实现第三方登录。
- B09：图中出现钱包充值和商豆；真实产品无用户充值钱包、无商豆，仅有奖励账户、收益明细和提现。
- B10：图中出现商家余额、线索 CRM 和商家套餐；只复用工作台、列表和数据看板布局，不自动增加这些功能。
- B11：图中出现普通会员、商家会员、团队长 Pro；真实产品只有一种 Pro 会员，月/季/年只是期限 SKU。
- 所有图片中的金额、日期、人数、收益、分类、标签和文案均为占位数据。

## 绑定规则

每个实现页面必须在 `catalogs/screen_visual_binding.csv` 中找到：

- Screen ID
- 主参考批次
- 主参考面板
- 参考方式
- 需要忽略的虚拟内容

若无精确面板，使用 Design Token 和相邻组件参考，不得自行扩张功能。
