# 合伙云 Pro 效果图视觉规则 V1.0

**状态：** 效果图生成前冻结基线  
**适用：** Android App、公开 H5 页面  
**不适用：** 后端、数据库、业务规则设计  
**日期：** 2026-07-16

## 1. 效果图的唯一职责

效果图用于表达页面布局、视觉层级、组件摆放、品牌风格和交互状态参考。

效果图不作为功能、接口、数据库、权限、金额、比例、时限和状态机的依据。

发生冲突时，执行优先级：

1. 完整项目开发文档
2. 已确认业务规则和变更单
3. `hhy_design_tokens_v1.0.json`
4. 组件规范和页面规格
5. 页面绑定清单
6. 组合效果图
7. AI 或开发者推测

效果图中出现但开发文档没有定义的按钮、字段或功能，不得擅自开发。开发文档要求但效果图未清楚表现的功能，仍按开发文档实现。

## 2. 品牌视觉定位

- 品牌：合伙云 / 合伙云 Pro
- 关键词：简洁、大气、可信、轻科技、高效连接、推广增长、红包激励
- 视觉母题：云朵、连接节点、合作关系、向上增长、流量光点、内容聚合
- 禁止：博彩大厅、纯金融理财、加密货币、游戏商城、完全仿微信或其他平台

### Android App

- 仅浅色模式
- 云白浅灰背景，白卡轻阴影
- 湖蓝或科技蓝主色
- 红包使用红金强调
- Pro 使用蓝紫渐变
- Material 3 和 Android 交互习惯
- 禁止 iOS 状态栏与 iOS 控件

### H5 宣传下载页

- 深蓝、靛紫、青蓝科技渐变
- 云端连接、流量光点、玻璃卡片、手机模型
- 首屏有口号、产品说明、下载按钮和二维码
- 版本号、APK 大小、SHA256 仅放底部辅助区

规则：

- 卡片标题最多两行
- 摘要最多两至三行
- 标签和昵称单行省略
- 详情正文自适应
- 不固定文字容器高度
- 测试 1.0 / 1.15 / 1.30 字体比例
- 不得用超大文字破坏布局

## 6. 核心组件

### 顶部导航
56dp；图标统一 24dp；同一级页面使用同一返回图标；右侧最多两个操作。

### 底部导航
固定：**首页 / 红包 / 发布 / 消息 / 我的**。  
图标统一，切换不得灰闪；中央发布按钮可突出但不能破坏基线。

### 内容卡片
统一骨架：内容类型、封面或 Logo、标题、摘要、属性标签、发布者、Pro 标识、数据和红包/头条/置顶状态。四类内容不得各做一套完全不同的视觉语言。

### Pro 标识
蓝紫渐变，文案固定 `Pro`。月、季、年使用同一公开标识，不得与官方、实名、企业认证混淆。

### 红包计时浮球
56dp 红金渐变圆形；外圈进度环；显示剩余秒数；滚动时缩小；完成后轻震动、金色粒子和领取底部弹层；不得遮挡正文。

### 聊天输入区
表情与扩展面板从底部自然展开，输入框和最近消息保持可见，不使用遮住整个聊天页的大弹窗。

## 7. 页面状态

关键页面必须覆盖：

- 默认
- 加载/骨架
- 空数据
- 网络失败
- 无权限
- 未实名
- 禁用
- 提交中/成功/失败
- 审核中/驳回
- 内容下架
- 红包暂停/领完
- 支付处理中
- 提现审核中
- 链接或二维码失效

组合图只展示代表状态；完整状态以页面规格为准。

## 8. 8 页面组合预览图

每批只生成一张图，包含 8 个页面。

- 推荐尺寸：3072×3072px
- 最低：2048×2048px
- 固定 4 列 × 2 行
- 每格一个竖屏页面
- 薄手机边界，不使用厚重设备外壳
- 页面间距 32–48px

固定位置：

| 位置 | 编号 |
|---|---|
| 第一行第1列 | P01 |
| 第一行第2列 | P02 |
| 第一行第3列 | P03 |
| 第一行第4列 | P04 |
| 第二行第1列 | P05 |
| 第二行第2列 | P06 |
| 第二行第3列 | P07 |
| 第二行第4列 | P08 |

每格必须有 `P01–P08` 编号徽标和简短中文页面名。完整页面名与功能以 Manifest 为准，不依赖图片中文字识别。

组合图顶部统一显示：

- 合伙云 Pro
- 第 XX 批
- 模块名
- 8 页面组合预览
- 仅供 UI 布局与样式参考，功能以开发文档为准

生成限制：

- 中文界面，通用 App / Pro / Android / QQ 除外
- 不出现 iOS 状态栏
- 不加入开发文档外的新功能
- 不虚构夸张收益数字
- 8 个页面不得重复
- 所有页面必须明显属于合伙云 Pro
- 同一批导航、圆角、字号和卡片风格统一

共 12 批，96 个参考页面：

1. 启动与登录
2. 首页与四类内容卡片
3. 四类内容详情与发布者主页

6. App、群聊、团队长发布
7. 消息、私聊、通知、公告
8. 我的、发布管理、订单

11. 实名、奖励账户、提现、设置

## 10. 批次审核

通过条件：

- 8 个页面完整
- P01–P08 位置准确
- 页面与绑定表一致
- 属于合伙云 Pro
- Android 风格统一
- 字体比例正常
- 卡片、边距和圆角一致
- 无重复页
- 无开发文档外的关键功能
- 放大后主要布局可辨识

状态：

- DRAFT
- REVISION_REQUIRED
- APPROVED
- SUPERSEDED

## 11. 归档

每个合格批次保存：

```text
design/previews/BXX/
├── HHY_BXX_8PAGE_PREVIEW.png
├── HHY_BXX_MANIFEST.json
├── HHY_BXX_REVIEW.md
└── HHY_BXX_PROMPT.md
```

页面绑定必须记录：批次、P 编号、Screen ID、页面名、开发文档章节、图片 SHA256、审核状态和确认日期。

## 12. 开发边界

Codex 不得：

- 从效果图猜测后端字段
- 根据虚拟金额改变规则
- 因图片没画某功能而删除需求
- 因图片多出按钮而自行开发
- 逐像素写死页面高度
- 自行新增颜色、字号和圆角
- 把组合图当成唯一验收依据

开发优先还原布局、信息层级、卡片关系和品牌样式；精确数值以 Token 和页面规格为准。
