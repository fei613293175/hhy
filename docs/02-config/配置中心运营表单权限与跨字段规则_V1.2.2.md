# V1.2.2 配置中心运营表单、权限与跨字段规则

## 规模与结论

- 配置项：**314**
- 职责角色：**21**
- 跨字段规则：**58**
- 每项配置均已定义显示名、分组、控件、单位、范围、步长、正则、依赖、编辑角色、复核角色、影响预览、回滚和审计事件。

## 配置页面实现要求

- 保存只产生草稿；激活与回滚形成不可变新版本。
- SecretRef 只显示配置状态，不回显秘密，不允许明文默认值。
- 保存前展示字段错误；提交审批前展示跨字段结果、旧/新差异、依赖和受影响范围。
- 生产、资金、安全、域名、签名和供应商秘密变更必须双人复核。
- 运行时热更新只能用于声明支持原子刷新且完成兼容验证的业务配置。
