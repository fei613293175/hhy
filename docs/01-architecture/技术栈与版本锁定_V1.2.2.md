| 层 | 锁定版本/策略 |
|---|---|
| Backend | Java 21、Spring Boot 4.1.0、Maven Wrapper 3.9.11、Flyway、PostgreSQL 17.10 |
| Android | 构建 JDK 21、Java bytecode 17、AGP 9.2.1、Gradle 9.4.1、Built-in Kotlin / Compose Compiler 2.3.21、Compose BOM 2026.06.01、compileSdk 37、targetSdk 36、minSdk 26 |

## 升级规则

版本升级只能由显式 Change Request 发起。升级提交必须同时更新本文件、锁文件、CI 和生成器，并通过：OpenAPI/状态机/迁移语义门禁、后端 `clean verify`、Web 类型检查/测试/生产构建以及 Android lint/单测/Debug APK 构建。业务版本不得隐式漂移工具链。

## 构建入口

- 后端：`services/backend/mvnw`，不得依赖开发机全局 Maven；
- Android：`apps/android/gradlew`，不得依赖开发机全局 Gradle；
- Web：根目录 `pnpm-lock.yaml` 与 `packageManager` 字段；
- Python 门禁：`scripts/project-doctor.py --strict`。
