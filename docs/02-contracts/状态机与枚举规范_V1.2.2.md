# 状态机与枚举唯一事实源

V1.2.2 起，状态名称只允许来自以下两个机器可读文件：

- `database/enum_registry.yaml`：枚举集合与兼容规则；
- `database/state_machines.yaml`：初始状态、终态、转换、权限、前置条件、副作用和幂等键。

数据库、Java/Kotlin/TypeScript 枚举必须由上述文件生成或在 CI 中逐项比对。文档中的自然语言状态不得另造同义词。

## 强制规则

1. 状态改变必须校验 `expectedVersion`，并写入对应状态历史表。
2. 状态改变产生的跨模块副作用必须写 Outbox，不得在控制器中直接串行调用多个领域 Repository。
3. 支付、红包、奖励、提现等状态转换必须同时满足账务不变量。
4. 通配来源状态 `*` 仅用于平台封禁、删除、终止等受审计高风险动作。
5. 新增或重命名状态必须包含数据库迁移、前后端类型更新、状态图更新、兼容策略和测试。
