# 测试策略与质量门禁 V1.2.2

## 测试金字塔

1. 领域单元与属性测试：状态机、价格、权益、账务、配额、风控规则。
2. 数据库集成测试：真实 PostgreSQL、迁移、唯一约束、锁与并发。
3. 契约测试：OpenAPI 请求/响应、错误码、安全声明和消费者兼容。
4. 模块集成测试：Outbox/Inbox、第三方适配器、回调、重试和对账。
5. UI/E2E：仅覆盖注册、发布、支付、红包领取、提现等关键链路。
6. 安全/性能/故障注入：越权、重放、限流、并发、消息重复、Redis/MQ/供应商异常。

## 阻断门禁

- `scripts/project-doctor.py --strict`
- 后端 `./gradlew test`
- Web `pnpm typecheck && pnpm test && pnpm build`
- Android `./gradlew lint test assembleStagingDebug`
- 空库和升级库 Flyway 迁移
- 复式记账借贷平衡、余额重建、红包不超发、回调幂等属性测试
- 仓库 Secret 扫描、依赖漏洞扫描、SAST 与最小权限检查

测试目录 `catalogs/test_cases.csv` 是测试计划索引；每项必须关联自动化路径、固定数据集和验收证据。
