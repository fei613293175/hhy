# 本地开发与立即开工指南 V1.2.2

## 1. 首次验证

```bash
cp .env.example .env
make doctor
make infra-up
make install
make backend-test
make web-test
make web-build
make android-test   # 需 Android SDK API 37；CI 执行相同门禁
```

`make verify` 汇总运行 Project Doctor、后端测试、Web 类型检查/测试/构建。Android 因 SDK 体积和签名环境独立运行，但在 CI 中为必过 Job。

## 2. 第一批可并行工作

- Lane A：P00/R01 工程、设计系统、代码生成、迁移、观测与 CI；
- Lane B：R02 账号安全，使用本地 SMS Provider、基础 RBAC 和版本检查；
- Lane C：R03 供应商配置中心与真实 Provider 适配；
- Lane D：R04 媒体上传；
- Lane E：R05 实名，在 R02/R04 绿灯后集成。

并行不代表越过依赖。`releases/RELEASE_DEPENDENCIES.yaml` 是唯一依赖图，未满足前置版本验收证据时不得把后续能力标记完成。

## 3. 单个需求的实施顺序

1. 从 `NEXT_TASK.yaml` 和 `releases/<release>/TASKS.yaml` 领取任务；
2. 在 `catalogs/ui_action_matrix.csv` 找到动作级 operationId、Schema、权限、幂等键、错误状态和测试；
3. 只从冻结契约生成 DTO，禁止页面、Controller 或数据库实体各自定义同义字段；
4. 变更状态机、枚举、资金、接口或数据表时先创建 CR/ADR，再同步事实源与迁移；
5. 增加单元/集成/并发/恢复测试并运行门禁；
6. 回填 Session Log、追踪矩阵证据和 `CURRENT_STATUS.yaml`。

## 4. 环境与秘密

`.env.example` 只含本地占位值。真实短信、实名、支付、出款、对象存储、推送、签名和生产数据库秘密必须通过 SecretRef 注入；不得提交 `.env`、证书、keystore、私钥或供应商原始回调样本。
