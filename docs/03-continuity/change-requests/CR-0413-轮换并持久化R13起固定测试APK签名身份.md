# CR-0413 — 轮换并持久化R13起固定测试APK签名身份

## 用户需求摘要

项目所有者要求完成R13桌面APK交付并持续推进；旧固定测试签名私钥缺失，必须建立可跨电脑和AI复用的新长期测试签名

## 原规则

R06至R12固定测试签名指纹为f17b0407，但仓库只有证据且没有可解析SecretRef，私钥遗失后无法继续稳定覆盖签名

## 新规则

从R13起固定使用hhy-staging-test-v2；私钥与随机口令仅保存在obx-test root-only持久目录，仓库只记录secretref://obx-test/hhy/android/test-signing/v2、证书SHA-256和轮换边界。所有R13至后续TEST_APK必须复用该Profile，禁止临时debug或随机签名

## 修改原因

R06至R12仅留证书指纹且本机、obx-test常用目录、Docker卷和GitHub Secrets均无对应私钥；旧APK无法恢复私钥，随机debug签名也不能作为稳定交付身份

## 影响摘要

建立可跨电脑和AI恢复的长期测试签名身份，并明确旧签名到v2的不可逆轮换；不影响生产签名或应用业务数据
