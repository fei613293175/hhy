# CR-0221 — 按效果图级标准回补R07搜索与发布者页面视觉

## 用户需求摘要

全部既有与后续版本UI肉眼接近效果图丰富度和精致度，不虚构内容或功能，R02至R07历史页面作为R08候选前置回补

## 原规则

CR-0213已要求历史页面达到效果图级丰富度与精致度；R07三张非敏感候选截图已保留，但验收目录明确标记搜索首页、结果页和发布者主页为BLOCKED_REDESIGN。

## 新规则

不新增规则；按既有CR-0213和逐页冻结规格回补R07。搜索区改为完整组合卡，历史与热词使用紧凑标签层级；结果卡按B02内容卡语言形成类型、标题、摘要和真实发布者动作层级；发布者头和公开内容卡按B03/P05语言强化资料、标记、内容与联系区，但只使用现有服务端字段，不增加图片、指标、关注或营销功能。

## 修改原因

R07候选截图证明功能和参数合规，但搜索首页、结果卡和发布者资料卡信息层级与B02/B03参考存在明显视觉差距，ui_visual_acceptance已标记BLOCKED_REDESIGN

## 影响摘要
