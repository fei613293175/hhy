# CR-0219 — 登记R08三页精确视觉施工合同

## 用户需求摘要

所有UI肉眼接近效果图丰富度和精致度，不虚构业务；无直接效果图时复用相关页面风格。

## 原规则

既有唯一UI规则要求逐页精确面板或批准补充规格；R08页面目录当前仅提供范围引用或Token，不能直接作为验收合同。

## 新规则

不修改硬规则、不新建目录事实源：在既有catalogs/ui_visual_acceptance.csv登记SCR-LIST-001=B02/P05、SCR-DETAIL-001=B03/P01；SCR-PUB-002使用批准补充规格复用B02/P05的信息分组、B03/P01的品牌层级和既有MOB-FORM交互，仅允许冻结字段与状态。

## 修改原因

现有页面目录将R08来源写成B02/P01-P08范围和TOKENS_ONLY，视觉门禁禁止范围引用并要求逐页精确来源；需在既有ui_visual_acceptance唯一目录登记三页合同，发布编辑页形成批准补充施工规格。

## 影响摘要

新增三份R08逐页施工规格并更新既有视觉验收目录；规格是页面派生合同，不是新的全局硬规则。当前先登记IN_REVIEW，候选截图经AI肉眼对照后才能PASS。
