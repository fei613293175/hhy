# CR-0519 — 修复R13与R14长表单底部操作安全区及历史页顶栏裁切

## 用户需求摘要

大版本最终由AI审核GitHub Actions截图，所有UI必须按效果图和开发文档判断合格，不合格时自行修复并持续推进。

## 原规则

长内容底部面板整体使用单一Column滚动或包裹内容；操作按钮可能随正文落出首屏，历史视觉测试只检查文字存在和截图数量，未检查固定操作区与安全区像素结果。

## 新规则

R13失效反馈和R14聊天举报使用受屏幕约束的底部面板：正文独立滚动，主次操作固定在导航安全区上方且IME下始终可达；历史视觉必须断言顶栏和操作区可见，并由AI逐图拒绝系统栏覆盖或裁切。

## 修改原因

Run 30516346703执行33张离线视觉审计PASS，但AI逐图复核发现R13失效反馈与R14聊天举报操作区被系统手势条覆盖，R14按钮落出首屏，R13浏览记录顶栏被裁切；绿色执行结果不能替代视觉验收。

## 影响摘要

只修复R13/R14三个已取证视觉面及其离线审计；不修改API、数据库、业务字段、提交状态机、最终候选APK或公网数据。
