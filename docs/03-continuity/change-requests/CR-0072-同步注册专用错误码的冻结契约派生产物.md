# CR-0072 — 同步注册专用错误码的冻结契约派生产物

## 用户需求摘要

细化注册错误提示并保持跨客户端契约一致。

## 原规则

运行时契约仍为注册通用业务错误，contract_status指向旧源哈希。

## 新规则

运行时契约同步手机号已注册、邀请码无效和密码策略专用错误码，所有契约状态哈希与新冻结源一致。

## 修改原因

OpenAPI和错误码源变更后，运行时副本与contract_status哈希必须同步。

## 影响摘要

仅同步生成的运行时契约副本和状态哈希，不改业务实现。
