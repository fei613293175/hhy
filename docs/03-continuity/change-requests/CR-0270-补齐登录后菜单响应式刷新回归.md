# CR-0270 — 补齐登录后菜单响应式刷新回归

## 用户需求摘要

项目所有者要求立即修复后台并完成真实可用性验证。

## 原规则

CR-0269要求菜单按当前会话权限过滤，但App.vue的computed没有读取任何响应式会话字段，登录前空结果会被缓存。

## 新规则

不新增并列规则；菜单过滤computed必须依赖登录导航的响应式route状态，并由App组件测试证明登录后立即渲染授权菜单、隐藏未实现菜单。

## 修改原因

CR-0269首次线上登录发现权限已返回59项但App菜单computed未依赖响应式状态，登录前空菜单结果被缓存；需补最小响应式依赖和组件回归。

## 影响摘要

仅修复后台菜单登录后响应式刷新，不改变权限、API、数据库或密码。
