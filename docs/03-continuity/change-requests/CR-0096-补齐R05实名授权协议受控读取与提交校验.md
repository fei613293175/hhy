# CR-0096 — 补齐R05实名授权协议受控读取与提交校验

## 用户需求摘要

用户要求严格完成R05全部细节、不得依赖APK硬编码并持续推进

## 原规则

Android从HHY_IDENTITY_CONSENT_VERSION构建变量取得版本，服务端只保存客户端文本且不核对当前生效协议

## 新规则

新增GET /api/v1/identity/consent，从agreements当前生效IDENTITY_VERIFICATION版本返回标题和正文；创建会话必须提交同一不可变版本ID并由服务端二次校验；Android进入表单自动加载并可阅读正文，移除APK构建版本变量

## 修改原因

客户端当前依赖构建环境变量提供consentVersion，服务端不验证是否为当前生效版本，测试环境也没有可读取实名授权正文

## 影响摘要

解除PROB-0044，避免硬编码、空版本和旧版本静默提交；不向页面展示技术版本ID
