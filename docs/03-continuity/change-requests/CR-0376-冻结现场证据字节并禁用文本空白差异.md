# CR-0376 — 冻结现场证据字节并禁用文本空白差异

## 用户需求摘要

项目所有者批准持续开发并要求可复用经验写入仓库事实源，常规开发决策不再逐次确认。

## 原规则

artifacts/validation/**仅设置-text保留原始字节，Git仍对新增Prometheus/HTTP协议证据执行文本空白差异检查。

## 新规则

在同一既有.gitattributes规则上追加-diff：现场验证证据继续逐字节冻结并参与SHA-256、Secret和Scope门禁，但不按源代码文本执行尾空格或行尾差异检查。

## 修改原因

既有.gitattributes仅对artifacts/validation/**设置-text，能保留原始字节但仍按文本diff检查；Prometheus和HTTP原始协议证据含合法尾空格，新增文件会被git diff --check误拒绝，删除空格又会破坏远端本地SHA-256一致性。

## 影响摘要

原位更新一条既有Git属性规则，解决原始协议证据与源码空白门禁冲突；不修改任何证据字节、业务代码、测试结果或运行时。
