# CR-0089 — 区分R05实现入口与R02外部真机发布门禁

## 用户需求摘要

项目所有者要求未明确暂停前持续推进整个项目开发，并要求遇到一般问题自行决定

## 原规则

R05入口要求依赖版本GREEN，但R02仅剩旧APK项目所有者真机验收和版本关闭未完成，若把外部门禁等同实现缺失会导致全部后续开发停工
