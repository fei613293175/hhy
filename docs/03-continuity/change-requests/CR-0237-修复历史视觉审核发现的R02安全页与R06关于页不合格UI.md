# CR-0237 — 修复历史视觉审核发现的R02安全页与R06关于页不合格UI

## 用户需求摘要

项目所有者要求历史未达页面按肉眼接近效果图丰富度与精致度修复，效果图虚构内容不得开发，截图由AI独立判断

## 原规则

沿用CR-0213固化的唯一视觉规则、冻结页面规格和效果图绑定：肉眼应接近效果图丰富度与精致度，禁止实现效果图中的虚构内容；用户可见文案不得泄漏debug、P00或内部测试术语。

## 新规则

不新增平行规则；仅按既有唯一视觉规则修复SCR-AUTH-007、SCR-AUTH-008、SCR-ABOUT-001的不合格实现，并增加自动回归防止技术文案再次泄漏。

## 修改原因

R08历史截图逐图审核确认SCR-AUTH-007缺少B12-P03关键层级、SCR-AUTH-008风险动作层级扁平、SCR-ABOUT-001泄漏debug和P00测试文案，均不得标记PASS

## 影响摘要

丰富修改密码页和注销页的真实信息层级与安全提示；关于页只呈现清洗后的公开版本号和面向用户的更新说明；API、数据库、账本与运行配置不变。
