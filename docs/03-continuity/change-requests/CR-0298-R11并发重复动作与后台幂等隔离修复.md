# CR-0298 — R11并发重复动作与后台幂等隔离修复

## 用户需求摘要

立即开始并持续推进开发；所有终端命令静默执行

## 原规则

团队长详情动作仅使用稳定幂等键但未阻止同一资源重复并发；后台幂等键工厂仅按operation保存单槽

## 新规则

团队长详情同一时刻只允许一个写动作，动作失败保留已加载详情并允许同体同键重试；后台幂等键按operation与资源作用域隔离，成功仅清理对应作用域

## 修改原因

专项测试审计发现Android详情动作缺少单写锁且失败丢失已加载上下文，后台不同内容命令共享operation级幂等槽，均会导致重复或错误请求

## 影响摘要

增加Android纯状态动作门禁并接入详情按钮；动作错误转为局部提示；扩展后台幂等键工厂作用域并让内容及字典命令按资源隔离；补回归测试
