# CR-0476 — 解除R13历史候选测试对当前请求的永久绑定

## 用户需求摘要

R14至R32持续开发不得再发生跨版本开发和测试漂移

## 原规则

R13历史候选测试同时验证R13旅程和当前全局候选请求必须永远等于R13 Attempt20

## 新规则

R13历史测试只验证R13夹具、旅程、视觉合同及全局versionCode单调一致；当前候选请求的release、attempt、request_id和例外策略只由scripts/android_candidate_request.py及tests/test_android_candidate_request.py按当前版本验证

## 修改原因

GitHub CI 30404133115明确证明test_r13_candidate把当前config/android-candidate-request.yaml硬编码为R13 Attempt20，R14合法候选请求后产生确定性假失败

## 影响摘要

删除一个跨版本时间绑定断言并登记根因；不放宽候选请求校验、R13历史旅程、versionCode一致性或R14候选门槛
