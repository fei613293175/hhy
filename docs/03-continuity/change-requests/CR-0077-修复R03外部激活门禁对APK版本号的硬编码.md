# CR-0077 — 修复R03外部激活门禁对APK版本号的硬编码

## 用户需求摘要

用户要求注册修复后持续开发并交付可覆盖安装新APK

## 原规则

外部激活门禁要求三处Android版本文件都包含固定字符串10204

## 新规则

门禁解析三处versionCode并要求相互一致、不得低于R03基线10203，且与当前APK清单一致

## 修改原因

外部激活检查固定匹配10204会错误阻断合法单调递增的10205及后续测试包

## 影响摘要

消除合法APK版本递增后的假失败，不放宽版本回退、身份不一致和交付清单门禁
