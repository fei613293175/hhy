# CR-0269 — 修复后台权限会话菜单与生产可用性

## 用户需求摘要

项目所有者要求立即修复后台菜单错误跳页、配置不可用、超级管理员权限不足、滚动联动和刷新掉登录等问题，并继续开发。

## 原规则

后台菜单直接展示全部目录页面，页面权限依赖目录读取权限，SUPER_ADMIN由各迁移零散绑定权限；访问令牌只在页面内存保存，无权限统一回安全页。

## 新规则

后台菜单只展示已真实实现且当前会话有读取权限的页面，菜单组中文化；配置与域名使用后端真实权限码；SUPER_ADMIN自动拥有全部已登记权限；刷新和深链在当前标签页恢复会话，关闭标签页失效；无权限进入独立403页；左右栏独立滚动。

## 修改原因

线上实测确认SUPER_ADMIN仅22/59权限，配置路由权限码错配，64个菜单中52个为未实现占位，会话仅内存保存且无权限错误跳安全页。

## 影响摘要

修复后台基础可用性，不宣称未实现的52个占位功能完成，不改变管理员密码，不放宽具体管理动作权限。
