# CR-0022 — 补齐并行长期授权的模板与跨设备恢复回归

## 用户需求摘要

项目所有者要求长期多代理授权在任意AI工具和任意电脑上默认恢复。

## 原规则

根入口可更新，但导出模板START_HERE仍可能保留旧规则，且自测未断言新目录只靠仓库恢复长期授权。

## 新规则

导出模板必须携带与根入口一致的长期自动委托规则；生命周期自测和专门回归必须证明复制到新目录或新电脑后Context Pack仍显式恢复该授权。

## 修改原因

CR-0021独立审查后发现导出模板START_HERE和无状态恢复自测未列入原影响文件，若不补齐可能在新包或新电脑恢复时丢失授权。

## 影响摘要

补齐模板入口和跨设备Context Pack恢复回归，防止打包、换AI或换电脑时授权漂移。
