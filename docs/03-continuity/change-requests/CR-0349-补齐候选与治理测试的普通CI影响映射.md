# CR-0349 — 补齐候选与治理测试的普通CI影响映射

## 用户需求摘要

全局检查开发文档、硬性门禁规则、开发进度、优点复用和踩坑记录，发现漂移立即加固。

## 原规则

普通CI按受影响模块选择Job；候选历史回归和治理知识门禁属于tooling事实，修改后必须运行对应回归，未受影响的Android、数据库和Web继续跳过。

## 新规则

既有test-impact-map增加候选历史与治理知识两个精确tooling检查：历史candidate测试或视觉归档变化运行候选测试发现；严格Doctor、治理知识与三份经验事实源变化运行治理结构回归。影响映射自身由既有加速测试验证，禁止用全量Android候选补证。

## 修改原因

CR-0348推送后的CI run 30187349464把已修改的历史候选测试和严格Doctor判定为tooling skipped，证明现有test-impact-map遗漏候选历史回归与治理知识门禁路径。

## 影响摘要

消除修改候选或治理测试却被普通CI错误skipped的假绿；tooling只在相关路径变化时运行，Android、数据库、Web仍按影响跳过。
