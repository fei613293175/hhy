# CR-0209 — 建立R08项目数据不变量与V033可回滚迁移

## 用户需求摘要

持续开发R08，普通任务只跑受影响MODULE，最终候选阶段再跑完整门禁和模拟器

## 原规则

R08复用V003/V006/V029数据骨架：内容类型、详情类型一致和版本/状态/审核历史不可变已存在，但内容状态值、项目字段、统计计数和版本号仍可写入空白或非数字值，项目列表缺少专用部分索引。

## 新规则

V033为新写入强制CONTENT_STATUS冻结枚举、project_details必填与可选字段非空白、content_stats非负数字字符串、content_versions非负整数版本号；阻止未软删除项目移除详情，增加项目公开列表和地区索引；复用全局idempotency_records唯一键，不新增表。

## 修改原因

R06只冻结通用内容类型和历史不可变规则，R08项目闭环仍缺内容状态枚举、项目字段完整性、统计数字字符串、版本号格式、项目检索索引及可回滚的真实PostgreSQL证据

## 影响摘要
