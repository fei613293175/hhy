# CR-0461 — 补齐序列恢复终态的连续性门禁枚举

## 用户需求摘要

强制修复连续性错误并确保后续不依赖聊天且门禁真实生效。

## 原规则

旧会话合法终态枚举只有CLOSED/ABANDONED/TRANSFERRED等，不认识经CR-0458审计新增的SEQUENCE_RECOVERED，因此恢复记录正确但pre-push拒绝。

## 新规则

在既有validate_session_structure终态枚举中加入SEQUENCE_RECOVERED；它仅是终态，不得被current_session视为ACTIVE/HANDED_OFF/CLOSING，也不得产生ACTIVE Claim。测试同时断言门禁接受该终态、旧会话不再被领取、当前唯一R14会话/Claim不变，并真实重跑pre-push。

## 修改原因

pre-push真实逐Commit校验发现continuity_gate仍拒绝CR-0458新增的终态SEQUENCE_RECOVERED；必须补齐同一状态机投影，不能绕过推送门禁。

## 影响摘要

只补齐连续性门禁对已批准序列恢复终态的识别，不改恢复状态、产品、API、数据库或版本计划。
