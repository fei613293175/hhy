# CR-0251 — R09 App推广跨端闭环与精确视觉实现

## 用户需求摘要

持续完成R09，所有UI按效果图丰富度和精致度实现，不虚构业务；普通任务仅受影响门禁。

## 原规则

R09页面目录使用整组预览或TOKENS_ONLY，App公开页把第三方下载链接写入自有发布包download对象。

## 新规则

App列表、详情、发布编辑分别以B02/P06、B03/P02、B04/P04为精确视觉施工源；第三方HTTPS下载和官网通过既有PublicPageBlockResource.action NavigationTargetResource表达，download只用于具备版本号、版本码和SHA256的自有发布包。

## 修改原因

App三页尚无Android实现，页面目录的视觉绑定过粗；H5 App分享页把第三方外部下载误套为自有APK发布包download结构，导致真实链接无法按冻结合同诚实展示。

## 影响摘要

实现Android App列表/详情/发布编辑及导航入口，完善H5 App分享真实动作和后台APP复用验证，补齐精确视觉规格与IN_REVIEW验收台账。
