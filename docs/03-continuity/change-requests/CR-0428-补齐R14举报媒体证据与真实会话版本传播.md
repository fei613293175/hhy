# CR-0428 — 补齐R14举报媒体证据与真实会话版本传播

## 用户需求摘要

持续按R14冻结客户端合同完成举报证据与expectedVersion，不虚构原因目录

## 原规则

R14举报面板只选择消息证据，ChatReportRequest虽然支持evidenceMediaIds和expectedVersion，但ChatDetail未接入AUDIT_EVIDENCE上传，AuthenticatedRoute.ChatDetail及四类直聊入口未传播服务端conversation.version，提交固定使用expectedVersion=null

## 新规则

SHEET-CHAT-002按FLD-01281复用既有MediaUploadSheet，以AUDIT_EVIDENCE用途只接受已授权图片，累计最多100项，展示非技术化证据序号并允许移除；二次确认同时显示消息和图片证据数量，提交严格传递evidenceMediaIds。AuthenticatedRoute.ChatDetail新增可空conversationVersion，只有会话列表ChatConversationResource.version或四类直聊创建响应R08ConversationResource.version可以赋值；ChatDetail将最后读取版本传给ChatReportRequest.expectedVersion，缺版本时明确禁用举报编辑和提交，不猜测、不写0、不继续传null冒充完整。PROB-0135原因目录为空时仍优先禁用，不关闭SHEET或Story

## 修改原因

STORY-R14-004审计确认FLD-01281媒体证据未接入，ACT-SHEET-CHAT-002-01要求expectedVersion等于最后读取的会话版本，但当前路由只传conversationId并长期提交null
