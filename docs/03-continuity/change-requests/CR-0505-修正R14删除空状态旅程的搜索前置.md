# CR-0505 — 修正R14删除空状态旅程的搜索前置

## 用户需求摘要

持续开发并由AI完成R14候选审核，不要求项目所有者逐项确认

## 原规则

解除拉黑后返回列表直接长按会话，并继续断言筛选空状态“没有找到相关会话”。

## 新规则

解除拉黑后返回列表必须在r14.conversations.search的Compose语义节点重新输入真实联系人、再次核对唯一联系人，再长按删除并严格断言筛选空状态“没有找到相关会话”。

## 修改原因

只修复ReleaseCandidateSmokeTest的搜索状态前置；不修改产品页面、API、数据库、空状态文案或既有业务断言。
