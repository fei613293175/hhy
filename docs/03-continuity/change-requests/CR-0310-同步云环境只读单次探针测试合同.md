# CR-0310 — 同步云环境只读单次探针测试合同

## 用户需求摘要

持续开发并完成R11机器关闭，不因确定性门禁问题停止

## 原规则

测试按旧版hostname、image id、volume列表三次SSH调用模拟云环境预检

## 新规则

测试必须按当前android_probe_command的一次SSH key=value输出验证镜像、Gradle缓存、API36平台卷、swap、可用内存、负载和构建锁；错误镜像以同一只读命令非零退出验证阻断

## 修改原因

云环境实现已合并为单次SSH key=value探针，但测试仍模拟旧版三次SSH返回，导致R11关闭全量Python测试两项误失败

## 影响摘要

仅同步过期单测与已存在的只读单次探针实现，不改云端环境、Android工具链、构建缓存或产品代码
