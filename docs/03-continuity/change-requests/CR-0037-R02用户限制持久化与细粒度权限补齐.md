# CR-0037 — R02用户限制持久化与细粒度权限补齐

## 用户需求摘要

用户要求持续推进R02并由Codex自行决定非紧急实现问题

## 原规则

R02故事仅列出users与user_status_logs等既有表，数据库基线为198表，细粒度user.restrict、user.freeze、user.security权限未物化。

## 新规则

新增R02 user_restrictions表保存每用户每类型当前限制、原因、到期、状态和版本；数据库事实调整为199表；物化三项冻结API权限并授予SUPER_ADMIN。

## 修改原因

冻结API要求限制类型、过期时间、解除和幂等，但当前数据目录只有用户状态日志，无法可靠表达多个当前限制及自动到期；同时user.restrict、user.freeze、user.security权限未落库。

## 影响摘要

使新增/修改限制、解除限制、到期判定和细粒度授权具备真实持久化与审计基础，不改变既有API路径或请求响应字段。
