# CR-0098 — 补齐R05活体照片安全下载边界

## 用户需求摘要

用户要求持续推进R05真实供应商闭环并保持商业系统安全边界

## 原规则

faceImageUrl仅完成HTTPS语法校验，尚无服务端下载边界，不能安全进入私有存储或人脸比对

## 新规则

新增ProviderFaceImageDownloader：只接受无凭据无片段HTTPS，解析出的全部IP必须为公网单播地址，禁止重定向，响应必须为JPEG或PNG且魔数一致，正文上限100KiB，并返回SHA-256；任何失败只映射为可重试实名认证服务不可用

## 修改原因

供应商结果已能返回faceImageUrl，但在保存private_kyc和人脸比对前必须先阻断SSRF、重定向、超限和伪造图片内容

## 影响摘要

将供应商照片URL转换为经过SSRF、大小和内容校验的内存字节，为private_kyc写入提供安全前置条件；不落盘、不写日志、不暴露URL
