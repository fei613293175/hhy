# CR-0347 — 纠正主开发文档定位指针并阻断事实源断链

## 用户需求摘要

项目所有者要求全局检查开发文档、硬门禁、开发进度、优点复用和踩坑记录，发现漂移立即原位加固。

## 原规则

SOURCE_OF_TRUTH已将根目录页面与运营规格冻结版列为产品业务权威主文档，docs/00-baseline内定位文件仅应指向该唯一事实源，派生指针不得形成第二套规则。

## 新规则

原位纠正既有定位文件，使其精确指向根目录合伙云Pro_完整项目开发文档_V1.2.2_页面与运营规格冻结版.md；V1.2.2与V1.2.3严格文档门禁同时验证定位文件存在、目标存在及文件名完全一致，防止跨AI接手断链。PATTERN-CONTINUITY-001和既有踩坑记录只补充可复用经验，不建立平行硬规则。

## 修改原因

docs/00-baseline中的现有定位指针仍引用仓库不存在的旧开发就绪版文件名，而SOURCE_OF_TRUTH与文档门禁使用页面与运营规格冻结版；当前严格文档门禁未检查该指针，跨AI接手存在断链风险。

## 影响摘要

消除一个已确认的主开发文档断链；不改变任何产品功能、页面、API、数据库、版本归属或当前R12实现，只加固现有事实源定位和严格文档回归。
