# CR-0514 — 建立仅离线历史视觉审计的推送触发入口

## 用户需求摘要

GitHub测试只在大版本最终审核使用，避免反复登录、后端和完整候选耗时；截图由AI自行判断且不中断开发

## 原规则

HISTORICAL-UI只有workflow_dispatch入口，但复用工作流未在默认分支Actions侧边栏暴露，换电脑或AI需依赖已登录浏览器手工操作。

## 新规则

新增路径限定的push请求工作流；只有config/android-historical-visual-request.yaml变化时运行，固定调用HISTORICAL-UI且candidate=false，因此不执行构建候选、OIDC、Staging或后端旅程。

## 修改原因

Android Quality Gate的HISTORICAL-UI工作流不在GitHub侧边栏显示，浏览器手工dispatch不可复用；需用仓库内不可变请求一次触发仅历史离线模拟器Job

## 影响摘要

新增一个可审计的一次性离线视觉请求入口与当前请求文件；不修改产品代码、候选、API、数据库、APK或生产部署。
