# 合伙云 Pro V1.2.1 正式开发发布说明

发布日期：2026-07-16  
基线状态：`READY_FOR_FEATURE_DEVELOPMENT`  
首个任务：`TASK-P00-001`

## 1. 发布结论

本包已经完成 V1.2 与前序 V1.2.1 工作区中能够在交付环境内复现和修复的问题，可以作为合伙云 Pro 的**正式开发基线**导入私有 Monorepo，并从 P00 开始受控研发。

该状态表示：产品范围、接口、状态机、数据库、配置、页面动作、发布依赖和工程骨架已具备一致的事实源与自动门禁；不表示 P00—R32 的业务功能已经全部实现，也不表示已经达到生产发布条件。

## 2. 本次直接关闭的问题

| 类别 | 修复结果 |
|---|---|
| OpenAPI 请求语义 | GET/DELETE 全部取消 JSON `requestBody`；每个操作均具备可解析的命名请求契约 |

| 校验器性能 | CSV/YAML 读取缓存及文件扫描剪枝，完整语义检查由数分钟降至约 5 秒 |
| 生成类型校验 | 按 `openapi-typescript` 实际输出结构校验，不再使用错误文本标记 |
| 可移植性误报 | 安全扫描不再扫描自身正则定义；仍扫描其余项目文件中的内部路径和敏感材料 |
| 中文目录构建 | Makefile 与 CI 固定 UTF-8 locale，消除 Java 中文路径不可编码问题 |
| 数据库真实门禁 | 新增 PostgreSQL 17.10 CI 服务和 `scripts/run_postgres_migration_smoke.sh` |
| 未解决事项治理 | 新增机器可读 `catalogs/development_risk_register.csv`，共 15 项版本化风险/外部门禁 |

## 5. 正式开发入口

```bash
export LANG=C.UTF-8
export LC_ALL=C.UTF-8
python3 -m pip install -r requirements-dev.txt
corepack enable
pnpm install --frozen-lockfile
make verify
```

然后按顺序读取：

1. `START_HERE.md`
2. `CURRENT_STATUS.yaml`
3. `NEXT_TASK.yaml`
4. `releases/P00/RELEASE_MANIFEST.yaml`
5. `releases/P00/TASKS.yaml`

正式研发从 `TASK-P00-001` 开始。任何契约、状态、表结构、配置生命周期或版本范围变化，必须先走变更请求并更新对应事实源与验证证据。
