# 契约、前后端对应与冻结门禁 V1.2

- `catalogs/frontend_backend_matrix.csv`：每个Android/H5/后台页面绑定版本、需求、API、表、配置、测试和UI参考。
- `catalogs/TRACEABILITY_MATRIX.csv`：需求到页面、API、表、配置、测试、Task和Commit的全链路。
- `contracts/openapi.yaml`、`admin-openapi.yaml`、`websocket-events.yaml`：唯一接口契约。
- `database/schema_dictionary.csv`、`enum_registry.yaml`：数据库契约目录。
- 当前目录中的 `CATALOG_BOUND` 是全项目规划级契约；对应版本开发前必须在任务001中补齐具体DTO/字段/错误码/示例并升级为 `FROZEN`。
- 前端不得自定义请求/响应字段；应从OpenAPI生成或做编译期契约校验。
- 后端不得先编码再补契约；数据库不得绕过迁移文件直接改生产Schema。
- 页面、API、表、配置或测试任一为空时，对应能力不得标记DONE。
